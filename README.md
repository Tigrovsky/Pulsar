Názov projektu: Pulsar

Autor: Branislav Lasch

Trieda: III.BTL



Cieľom projektu Pulsar je vyvinúť webovú aplikáciu pre používateľov streamovacej služby Spotify, ktorá im umožní podrobne analyzovať a vizualizovať ich štatistiky počúvania hudby za určité obdobie.



Aplikácia bude poskytovať:

* Prehľad najpočúvanejších skladieb, interpretov a albumov za rôzne časové obdobia.
* Vizuálne grafy a štatistiky hudobných žánrov či nálad počúvanej hudby.
* Integráciu so Spotify API prostredníctvom OAuth autentifikácie.
* Prehladné a intuitívne UI.



Postupm spustenia aplikácie: Aplikáciu je možné spustiť stiahnutím zdrojových kódov z repozitára a otvorením projektu v termináli. Následne stačí spustiť príkaz npm install na nainštalovanie všetkých potrebných balíčkov. Potom je potrebné aplikáciu rozbehnúť pomocou štartovacieho príkazu npm run dev. Na záver stačí otvoriť webový prehliadač a prejsť na lokálnu adresu
